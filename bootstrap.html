Investigación: Framework CSS Bootstrap 5

¿Qué es Bootstrap?

Bootstrap es el framework de código abierto de HTML, CSS y JavaScript más popular del mundo para el desarrollo de interfaces web responsivas y orientadas a dispositivos móviles (Mobile-First). Permite diseñar sitios modernos, estructurados y adaptables de manera rápida mediante clases utilitarias y componentes preconstruidos.

Ventajas de usar un Framework CSS: Estandarización de componentes, rapidez en el prototipado, soporte cross-browser garantizado y un sistema de grillas robusto que evita escribir cientos de líneas de media queries manualmente.
1. Concepto de Diseño Responsivo

El diseño responsivo asegura que el contenido y la disposición visual de una página web se adapten automáticamente al tamaño de pantalla y orientación del dispositivo del usuario (smartphones, tablets, laptops y monitores de escritorio) usando breakpoints estándar (xs, sm, md, lg, xl, xxl).

2. Sistema de Grillas (Grid System)

El sistema de diseño de Bootstrap se basa en una estructura flexible dividida en 12 columnas:

Elemento Función Ejemplo
.container / .container-fluid Contenedor base que envuelve, alinea y da márgenes laterales al contenido. <div class="container">
.row Fila horizontal que agrupa y organiza un conjunto de columnas mediante Flexbox. <div class="row">
.col-* (ej: col-md-6) Define cuántas de las 12 columnas ocupa un bloque según el tamaño de la pantalla. <div class="col-md-6">
3. Bootstrap vs. CSS Personalizado
Bootstrap 5
  • Estructura responsiva inmediata (Grid & Flexbox).
  • Utilidades rápidas de espaciado (m-*, p-*), colores y tipografías.
  • Componentes accesibles y probados.
CSS Personalizado (`styles.css`)
  • Identidad gráfica única del proyecto (temática Windows XP).
  • Bordes biselados, degradados específicos y sombras retro.
  • Reglas personalizadas no disponibles por defecto en Bootstrap.
4. Componentes de Bootstrap Aplicados en el Proyecto
  • Barra de navegación (navbar): Menú superior colapsable y adaptable a móviles.
  • Sistema de grillas (row, col-md-*): Distribución uniforme de perfiles, tablas informativas y portafolios.
  • Tablas responsivas (table, table-responsive): Visualización ordenada y desplazable de contenidos técnicos.
  • Botones y Badges (btn, badge): Botones interactivos y etiquetas de estado en las fichas de proyectos.
