Investigación: HTML5 y Semántica Web

¿Qué es el HTML Semántico?

El HTML semántico consiste en utilizar las etiquetas HTML para su propósito previsto, aportando significado a la estructura de la página tanto para los desarrolladores como para los navegadores, buscadores y lectores de pantalla.

Etiquetas Semánticas Principales
Etiqueta Descripción Uso en nuestro proyecto
<header> Contenedor de navegación inicial, títulos o introducción. Barra superior de navegación XP.
<nav> Sección que agrupa los enlaces principales de navegación. Menú con botones INICIO, EQUIPO, etc.
<main> Contenedor exclusivo para el contenido central del documento. Envuelve las ventanas activas de cada página.
<section> Bloque temático o sección independiente del contenido. Módulos de información y fichas de perfil.
<article> Contenido independiente y reutilizable (ej: proyectos, posts). Tarjetas de proyectos de cada integrante.
<aside> Contenido complementario o lateral secundario. Paneles laterales y notas informativas.
<footer> Pie de página con información complementaria o de autoría. Barra de tareas inferior estilo Windows XP.
Beneficios Clave
  • Accesibilidad: Permite que los lectores de pantalla para personas con discapacidad visual naveguen rápidamente por los bloques clave.
  • Posicionamiento SEO: Los motores de búsqueda indexan y comprenden la jerarquía del sitio con mayor precisión.
  • Código Limpio y Mantenible: Evita el exceso de etiquetas <div> sin significado ("divitis").
