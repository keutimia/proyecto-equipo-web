Guía de Referencia: Etiquetas HTML de Uso Común

Diccionario de Etiquetas Implementadas

A continuación, se documentan las etiquetas HTML más utilizadas en la construcción de interfaces web, indicando su propósito y un ejemplo real de cómo fueron aplicadas en la maquetación de nuestro sistema estilo Windows XP.

Etiqueta Cuándo es apropiado usarla Ejemplo de aplicación en nuestro sitio
<h1> a <h6> Para definir la jerarquía de los encabezados. <h1> es el título principal, descendiendo en importancia hasta <h6>. El <h1> se usó en el texto "Windows XP" de la barra superior. Los <h5> y <h6> estructuran los nombres y detalles técnicos en los perfiles.
<p> Para delimitar bloques de texto o párrafos estándar. Se utilizó para escribir las descripciones de roles, las reflexiones finales y las introducciones de cada investigación.
<a> Para crear enlaces hacia otras páginas o recursos externos. Aplicado en toda la barra de navegación y en los botones "Ver investigación..." que conectan los archivos del proyecto.
<img> Para incrustar imágenes gráficas en el documento web. Usado para mostrar las evidencias de Docker, las fotos de los integrantes y los íconos clásicos del Menú de Inicio.
<ul>, <ol>, <li> Para crear listas desordenadas (viñetas), ordenadas (números) y definir cada elemento individual de la lista. Se aplicaron <ul> y <li> para listar de forma limpia los lenguajes, herramientas e intereses en las tarjetas de perfil.
<div> Como contenedor genérico de bloque para agrupar elementos y aplicarles estilos CSS (layout). Fundamental en el proyecto: se usó masivamente con las clases de Bootstrap (row, col-md-6) y para formar las ventanas (xp_window).
<span> Como contenedor genérico en línea, ideal para aplicar estilos a fragmentos de texto sin romper el párrafo. Se usó para estilizar el nombre de usuario (xp_user_name) en el menú y los títulos de las ventanas sin generar saltos de línea.
<table> Para presentar datos de forma tabular (filas y columnas). Implementada en la investigación de Docker para organizar los 13 comandos de forma legible.
<form> y <input> Para capturar datos del usuario mediante controles interactivos (cajas de texto, checkboxes). Se utilizó un <input type="checkbox"> oculto como mecanismo lógico para hacer funcionar el despliegue del Menú de Inicio sin usar JavaScript.
<label> Para vincular un texto descriptivo a un control de formulario específico, mejorando la accesibilidad. Aplicada al botón "Inicio" verde; al hacer clic en el label, se activa el checkbox oculto que despliega el menú.
<button> Para elementos interactivos en los que el usuario hace clic para desencadenar una acción. Se usó para maquetar los controles de cerrar, minimizar y maximizar en la esquina superior derecha de cada ventana XP.
