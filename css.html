Investigación: CSS (Cascading Style Sheets)

¿Qué es CSS y cuál es su importancia?

CSS (Cascading Style Sheets) es el lenguaje utilizado para describir la presentación, el formato visual y el diseño de documentos estructurados en HTML. Su importancia radica en separar claramente la estructura del contenido de su capa visual, permitiendo mantener una identidad gráfica consistente y adaptable a múltiples dispositivos.

Estructura vs. Presentación: Mientras que HTML organiza el contenido y define la jerarquía lógica (títulos, párrafos, tablas), CSS determina cómo se visualiza dicho contenido (colores, fuentes, márgenes, bordes y alineaciones).
1. Formas de Aplicar CSS
Método Descripción Ejemplo de Código
En línea (Inline) Se aplica directamente en la etiqueta mediante el atributo style. <p style="color: blue;">Texto</p>
Interno (Internal) Se define dentro de la etiqueta <style> en el encabezado <head>. <style> p { color: blue; } </style>
Externo (External) Se enlaza un archivo .css independiente mediante la etiqueta <link>. Es el método más recomendado. <link rel="stylesheet" href="css/styles.css">
2. Selectores, Clases e Identificadores
  • Selector de tipo / etiqueta: Aplica estilos a todos los elementos del mismo tipo (ej. p { ... }, h1 { ... }).
  • Clases (.nombre-clase): Se pueden reutilizar en múltiples elementos para darles el mismo formato (ej. .xp_window, .xp_btn).
  • Identificadores (#nombre-id): Son únicos por página y se usan para elementos específicos (ej. #menuPrincipal).
3. El Modelo de Caja (Box Model)

Todo elemento en CSS es considerado una caja rectangular compuesta por cuatro capas:

Contenido (Content): El texto, imagen o elemento interno.
Relleno (Padding): Espacio interno entre el contenido y el borde.
Borde (Border): Línea que delimita el padding del margen.
Margen (Margin): Espacio exterior que separa la caja de otros elementos.
4. Estilos Personalizados Aplicados en Nuestro Sitio

En nuestro archivo central css/styles.css implementamos reglas para lograr la estética retro de Windows XP:

  • .xp_bar y .xp_taskbar: Degradados azules y posicionamiento fijo para la barra superior e inferior de tareas.
  • .xp_window: Bordes biselados, sombras suaves y fondos personalizados para emular ventanas del sistema operativo.
  • .xp_btn: Estilos de botones tridimensionales con efectos visuales para las acciones de minimizar, maximizar y cerrar.
